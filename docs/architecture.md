# 架构说明

`cloud-native-observability-distributed-tracing-sample` 演示 Express 应用中三类下游请求（HTTP / 存储 / 数据库）的分布式追踪埋点，segment/subsegment 语义与记录输出平台无关（结构化 JSON，可接 LTS/APM）。

## 组件

```
                            ┌────────────┐
                            │HTTP Client │
                            └──────┬─────┘
                                   │ requests
                                   ▼
┌────────────────────────────────────────────────────────────────────┐
│                  Express 应用（分布式追踪中间件）                  │
│           trace header / segment / subsegment / capture            │
└───────┬─────────────────┬─────────────────┬─────────────────┬──────┘
        │                 │                 │                 │
        ▼                 ▼                 ▼                 ▼
┌──────────────┐  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│ HTTP ROUTES  │  │  DOWNSTREAM  │  │    MYSQL     │  │  LTS / APM   │
│   请求入口   │  │ 下游调用捕获 │  │   查询捕获   │  │   日志上报   │
└───────┬──────┘  └───────┬──────┘  └───────┬──────┘  └───────┬──────┘
        │                 │                 │                 │
        └─────────────────┴────────┬────────┴─────────────────┘
                                   ▼
┌────────────────────────────────────────────────────────────────────┐
│                       平台无关的追踪核心模块                       │
│          segment 树构建 + 结构化日志输出（emit() 可插拔）          │
└────────────────────────────────────────────────────────────────────┘
```

## 核心

| 文件 | 说明 |
|---|---|
| `src/trace.js` | 平台无关追踪模块（TraceHeader/Segment/Subsegment/中间件/https+mysql 捕获） |
| `index.js` | Express 应用（3 路由） |
| `mysql-config.json` | MySQL 连接占位 |
| `package.json` | 依赖（express/mysql，零平台 SDK） |
